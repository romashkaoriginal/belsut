# Строительный факультет БелГУТ

React + Vite. Самостоятельный информационный сайт для абитуриентов и родителей. Основная палитра: navy blue и белый; синий и фиолетовый логотипа — дополнительные акценты.

## Запуск

`npm install`, затем `npm run dev`. Сборка: `npm run build`. Результат — `dist/`, подходит для статического хостинга.

## Содержание

- `src/data.js` — программы, данные плана приёма и источники.
- `src/main.jsx` — выразительные секции, выбор специальности, клавиатурная навигация и сравнение.
- `src/styles.css` — токены, адаптация, анимации и reduced-motion.
- `public/sources.html` — ограничения и происхождение данных для посетителей.
- `docs/content-decisions.md` — пересмотр исследования и список недостающих фактов.

Нет сервера, сбора личных данных и имитации отправки заявок. Иллюстрация — концептуальный мост, не фотография факультета. Данные 2026 года помечены как справочные. Для реального публичного запуска согласовать материалы и логотип с факультетом и подтвердить актуальные условия приёма.
